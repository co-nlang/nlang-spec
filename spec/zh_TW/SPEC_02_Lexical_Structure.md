# n/ Language Specification - 詞法結構與原子 (Lexical Structure)

本章節定義 `n/` 的語意前綴與基本字面量語法。

---

## 1. 命名空間前綴 (Namespace Prefixes)

`n/` 使用前綴符號來定義欄位在宇宙中的本體論角色。

### 1.1 座標身分原則 (Coordinate Identity Principle)
在 `n/` 的幾何空間中，欄位的完整身分（地址）由 **「前綴 + 名稱」** 共同決定：
*   **身分唯一性**：名稱相同但前綴不同的欄位（如 `age` 與 `@age`）被視為位於不同維度的幾何座標。
*   **合併限制**：格論合併運算 `&` 僅發生在「地址完全一致」的欄位之間。若 `fileA` 定義了 `/fib` 而 `fileB` 定義了 `fib`，它們在合併時不會碰撞，而是平行存在於 Combo 的不同索引面相中。

### 1.2 標準前綴表
| 前綴 | 名稱 | 角色 | 範例 |
| :--- | :--- | :--- | :--- |
| (無) | **Data** | **存有**:宣告路徑存在,索引至**資料軸**(data axis)。 | `age: 25` |
| **`@`** | **Type** | **邊界**:宣告幾何約束,索引至**型別軸**(types axis)。 | `@nat: 0..` |
| **`/`** | **Logic** | **變換**:宣告分派行為,索引至**規則軸**(rules axis)。 | `/add: x y -> x + y` |
| **`%`** | **Meta** | **元資訊**：宣告系統特徵，索引至核心元空間。 | `%len`, `%id` |
| **`~%`** | **System** | **系統**：反映引擎狀態，索引至系統命名空間。 | `~%Enum`, `~%List` |
| **`~`** | **Local** | **私有**：定義封裝邊界，索引至私有區域 (Local Home)。 | `~tmp: 123` |

> **軸語正名(2026-07-19,%kind 調和 B1)**:前綴索引的是**軸**
> (正交維度),不是欄位。舊表「索引至 `%data`/`%type`/`%rules`」
> 之 `%`-欄名拼法為舊代節點模型殘語(型別內容曾放 `%type` 欄);
> 節點內容形制之正典=同構原理 **SPEC_03 §4**(`%kind` 標角色,
> Type 角衍生內容欄=`%super`〔+ `%name` 反映〕;`%predicate` 退場
> →R2,見 SPEC_05 §3.2)。

*註：不具備 `_.` 或 `^.` 前綴的裸名稱路徑，遵循「由內而外」的詞法溯源規則 (詳見 **[SPEC_04](./SPEC_04_Navigation_and_Duality.md)**)。*

## 2. 原子字面量 (Atoms)

代表收斂終點的不可分割單元。 (詳細定義見 **[SPEC_01](./SPEC_01_Foundation_and_Lattice.md)**)

### 2.1 字串與特殊字面量
*   **字串**：
    *   **普通字串**：`"Hello"`。
    *   **多行字串**：使用三引號 `"""`。支援自動縮進修剪。
    *   **內插字串**：使用反引號 `` ` ``。使用 `${path}` 嵌入動態觀測值。
*   **前綴字串原子 (Prefixed Atoms)**：
    *   **`r"..."` (Regex)**：正則表達式。
    *   **`p"..."` (Path)**：路徑標識（Identity）。
    *   **`t"..."` (Time)**：ISO 8601 格式之時間，如 `t"2006-01-02T15:04:05Z07:00"`。
    *   **`b"..."` (Bytes)**：二進位位元組流（預設 Base64 格式）。
    *   **`u"..."` (URI)**：資源定位符。
*   **標籤與單元**：見 **[SPEC_01](./SPEC_01_Foundation_and_Lattice.md)** 之格論基礎原子。

### 2.2 數字 (Numeric)

`n/` 的數值系統建立在 **複數域 ℂ** 的量子化譜幾何之上。所有數字字面量本質上都是對 Hilbert 空間特徵值的觀測投影。

| 字面量形式 | 預設型別 | 語義說明 |
| :--- | :--- | :--- |
| `42`, `-7` | `@num` | **整數字面量**。觀測時投影為實數軸上的整數點（虛部為零）。 |
| `3.14`, `-0.5` | `@num` | **浮點字面量**。內部以雙精度表示，語義上屬於複數子空間。 |
| `2+3i`, `1.5-0.5i` | `@num` | **複數字面量**。顯式包含虛部，完整展現 ℂ 的結構。 |

#### 型別層次與投影

```
@num  (⊤ 數值萬有型)
  ├── @complex  (複數子空間：實部 + 虛部)
  │     └── @float   (連續實數投影：IEEE 754 雙精度)
  │
  └── @int     (離散整數投影：任意精度 BigInt)
        └── @u8..@u256, @i8..@i256  (固定寬度整數投影，用於 FFI 邊界)
```

*   **@num**：**譜萬有型 (Spectral Top)**。所有數值的幾何母空間。在 `n/` 中，`5` 實質上是 `5 + 0i`，可投影至複數實軸或離散整數格。
*   **@complex**：顯式複數型別。保留實部與虛部的雙重資訊，支援完整的複數運算（如 `exp(iπ) = -1`）。
    *   **與 @int 的關係**：`@complex`（連續 ℂ）與 `@int`（離散 ℤ）是**正交子空間**，同屬 `@num` 的並行投影。
*   **@float**：連續實數投影。符合 **IEEE 754 雙精度 (64-bit)** 標準，是 `@complex` 的實軸子空間。
    *   **特殊值處理**：
        *   **`NaN`**：禁止作為有效座標或值，觀測時坍縮為 **`_|_`**，標記 `%cause: #numerical_error`。
        *   **`Infinity`**：映射至序位最大元 **`#_`**。
        *   **`-Infinity`**：映射至序位最小元 **`#_|_`**。
    *   **捨入模式**：預設採用 **Ties to Even**。
*   **@int**：離散整數投影。任意精度整數（BigInt），用於精確計算與格論索引。

#### 量子化語義

*   **相位保留**：所有數值運算在內部保留幾何相位資訊，直到顯式觀測（如投影至 `@float` 或 `@int`）才發生相位坍縮。
*   **自動提升**：整數與浮點數混合運算時，自動提升為 `@num`（複數域）進行計算。
*   **型別約束**：`@float` 和 `@int` 可作為對 `@num` 的**幾何約束**（見 **[SPEC_09](./SPEC_09_Standard_Library.md)** §2 標準型別）。

## 3. 複合結構、匿名集合與區間 (Composites & Ranges)

除了基礎的 `{}` (Combo) 與 `[]` (List) 之外，`n/` 支援明確的**匿名集合與區間宣告**。
*   **`@{ ... }`**：強制將內部表達式解析為「集合」而非單一值。求值**透明**（2026-07-10 裁決）：`@{ e } ≡ e`（意圖標記在 parse 層；Union 本就是集合，`@{ 5 }` ＝ `5`）；空體 `@{}` ≡ `_|_`。`%kind` 型別邊界標記＝有意留白（SYNTAX_04 §4.7）。
*   **`[Start]..[End][..Step]` (Range)**：定義一個**區間集合**（非序列、非迴圈——物化為序列用 `~%List./range`，該態射 API 維持工程慣例的閉開 `[start, end)`）。
    *   **格論語義**：區間 `A..B` 本質上是一個 **「數值集合邊界 (Numerical Set Boundary)」**——符號化的格論值：觀測不物化、不塌縮；支援成員判定（`5 & 1..10` → `5`；`12 & 1..10` → `_|_`）、區間交集（`1..10 & 5..20` → `5..10`；空交集 → `_|_`；單點交集塌縮為原子）、宣告後精煉（`x: 1..10` 後 evolve `x: 5`，單調演化）。
    *   **端點（2026-07-10 裁決）**：有限端點**閉閉 [A, B]**——兩端屬於集合（`150 & 0..150` → `150`；`@u8` 幾何＝`0..255`，SPEC_09）。錨點端天然開（無窮不可達，SPEC_01 §2.6 範例照舊）。
    *   **步進行為 (Step)**：
        - **離散型別 (@int)**：預設步進為 `1`。
        - **連續型別 (@float)**：若未指定步進，視為**無限稠密的連續集合**。
    *   **預設邊界與無限 (Infinity)**：`#_` 與 `#_|_` 分別代表該型別的序位極限（見 **[SPEC_01](./SPEC_01_Foundation_and_Lattice.md)**）。在 `..` 區間中，若省略邊界（如 `1..`），預設以 `#_` 為終點、`..10` 以 `#_|_` 為起點——**序位錨點，非資訊格極值 `_`**（序極值 ≠ 資訊極值，兩格不得混用）。

## 4. 分隔符號與註解

*   **冒號 `:`**：分隔路徑/Key 與定義/Value。
*   **點 `.`**：路徑成員存取。
*   **註解 `;;`**：允許在行首或行尾使用。僅供閱讀，不參與收斂。

## 5. 運算子結合優先序 (Operator Precedence)

為了保證不同實作產生一致的 AST，`n/` 定義了嚴格的優先序。
完整優先級表格請參閱 **[SPEC_14](./SPEC_14_Formal_Grammar.md)** **§2.3**（最終權威）。
下表為快速參考：

**規則**：層級數值**越小**，結合越緊密（優先權越高）。

| Level | Operator | Name | Associativity |
| :--- | :--- | :--- | :--- |
| 1 | `_`, `_\|_`, `()`, `{}`, `[]`, `@{}` | 原子、複合字面量與分組 | N/A |
| 1 | `_.`, `^.`, `..`, `<<>>` | **路徑錨點、區間與水晶透視**（雙角括號，SPEC_14 §2.4） | N/A |
| 2 | `.`, `[]` | 成員存取與動態導航 (Lens) | Left-to-Right |
| 3 | **`@`** | **型別註解 (Annotation)** | Right-to-Left |
| 4 | `...` | 展開運算子 (Spread) | N/A |
| 5 | `!` | 單元運算（補集）——負號屬字面量（`-7` 為單一原子；W1-1，SYNTAX_02 §4.3） | Right-to-Left |
| 6 | `f x` | **態射應用 (Apply)** | Left-to-Right |
| 7 | `/op` | **中綴邏輯調用 (Infix Logic)** | Left-to-Right |
| 8 | `*`, `/`, `%` | 乘法、除法、取餘 | Left-to-Right |
| 9 | `+`, `-` | 加法、減法 | Left-to-Right |
| 10 | **`&`** | **集合合併 (Merge)**——比比較**緊**（與 C 相反；SPEC_14 §2.3） | Left-to-Right |
| 11 | `<`, `<=`, `=`, `>`, `>=`, `==`, `!=` | 比較運算、子型別判定（兩家族：格論 `< <= = >= >` 不塌縮／原子 `== !=` 塌縮） | Left-to-Right |
| 12 | **`\|`, `\`** | **集合聯集 (Union) 與 差集** | Left-to-Right |
| 13 | **`\|>`** | **演化管道 (Pipe)** | Left-to-Right |
| 14 | `? :` | **條件收斂 (Ternary)** | N/A |
| 15 | **`->`** | **態射定義 (Morphism)** | Right-to-Left |
| 16 | `:` | 定義與綁定 (Binding) | Right-to-Left |
