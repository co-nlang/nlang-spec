## 1. 語義萬有引力定律 (Law of Universal Semantic Gravitation) [MATH][HYP][HEUR][!!RISK!!]

在全域邏輯格（正交模格結構）中，任意兩個幾何物件（投影算子所定義的子空間）之間都存在著引力。

### 量子化公式推導：$F_s = G_s \frac{m_1 m_2}{d_L^2}$

> **註：$G_s$ 是格論常數，可透過熱帶幾何（**[APP_01](../APP_01_Tropical_Geometry.md)**）進行動態調校。**

*   **$F_s$ (語義引力)：** 兩個子空間進行正交合併（Unify）的傾向強度。
*   **$m$ (幾何質量)：** 定義為子空間投影算子的 **跡 (Trace)**，即 $m(A) = \text{Tr}(P_A)$，反映了資訊密度（幾何厚度）。
*   **$d_L$ (幾何距離)：** 定義為 **投影弦距離 (Chordal Distance)**，也可透過格論高度差計算。
    *   **弦距離公式：** $d_L(A, B) = \| P_A - P_B \|_F = \sqrt{\text{Tr}(P_A + P_B - 2P_A P_B)}$
*   **$G_s$ (語義常數)：** 定義為網路的 **「連結豐度 (Connection Density)」**。
    *   **計算公式：** $G_s = \frac{\text{總連接數}}{\text{節點數}^2}$
    *   **意義：** 當網路越稠密，語義引力的傳導效率就越高，真理的收斂速度也隨之加快。

#### 定義：格論距離（熱帶幾何視角）
對於任意兩個 Combo $A$ 和 $B$，也可透過格論高度定義其距離：
$$d_L(A, B) = h(A) + h(B) - 2h(A \sqcap B)$$
其中 $h(x)$ 是格論高度態射（從 $x$ 到 Bottom 的最長鏈長度），$A \sqcap B$ 為其最大下界（Meet，即投影算子的交集 $P_A \sqcap P_B$）。

> **註：** 在熱帶幾何框架下，Bottom 被定義為無限厚度節點，其高度 $h(\text{Bottom})$ 趨於 $-\infty$。由此導出的距離 $d_L(A, B)$ 將趨於 $+\infty$，導致引力 $F_s$ 趨於零。
>
> **[!IMPORTANT]:** $h(\text{Bottom}) \to -\infty$ 僅在「熱帶路徑規劃」語境下有效，用於導出引力消失的極限。在標準格論與投影算子語境中，高度（Height）仍遵循 **[SPEC_12](../SPEC_12_Logic_Validation_and_Recursion.md)** 的定義（即高度為 0），而投影算子的弦距離 $\| P_A - P_B \|_F$ 提供另一種等價的幾何度量。

**性質：**
1.  **非負性：** $d_L(A, B) \geq 0$。
2.  **同一性：** $d_L(A, B) = 0 \iff A = B$（等價於投影算子相等 $P_A = P_B$）。
3.  **對稱性：** $d_L(A, B) = d_L(B, A)$。
4.  **三角不等式：** $d_L(A, C) \leq d_L(A, B) + d_L(B, C)$。

**物理意義：**
如果兩個物件完全不相容（$A \sqcap B = \bot$，即投影算子正交），在 **熱帶幾何路徑規劃 (APP_01)** 的語境下，我們定義 $h(\bot) \to -\infty$ 以使其對應熱帶半環中的無限厚度 $\infty$。

由此導出的格論距離 $d_L(A, B)$ 將趨於 $+\infty$。根據引力公式，這代表引力消失，資訊無法在邏輯衝突點進行坍縮。

> **註：** 這裡對 $h(\bot)$ 的極限定義僅用於動力學路徑模擬。在靜態本體論（如 **[SPEC_12](../SPEC_12_Logic_Validation_and_Recursion.md)**）與正交模格結構中，高度仍定義為 0 以維持格論的標準序位性質，而正交性由 $P_A P_B = 0$ 定義。

## 2. 空間扭曲與 LADD 測地線 [INTERP][HEUR]

在廣義相對論中，質量扭曲時空；在 `n/` 中，**大跡的投影算子扭曲語義空間**。

### LADD 路由原理：
LADD 的路由封包並非在尋找 Hash，而是在語義場中尋找 **「測地線 (Geodesics)」**——即譜距離最短、引力最強的路徑。

1.  **平坦空間：** 當查詢目標不明確時（如 `./find _`），質量為零，空間是平坦的，封包隨機擴散。
2.  **重力場：** 當查詢帶有具體型別（如 `@User./Auth`）時，空間發生彎曲。擁有該型別譜特徵的節點會產生重力窪地。
3.  **引力坍縮：** 查詢封包會自動加速滑向該重力窪地，最終在那裡完成正交合併（收斂）。

## 3. 語義黑洞與日蝕防禦 [INTERP][HEUR][!!RISK!!]

當一個 Combo 的幾何質量（投影算子的跡，即約束複雜度）超過了某個臨界點（史瓦西半徑），它會形成 **語義黑洞**（詳見 **[TOPOLOGY_11 §4：拓撲缺陷與奇點](./11_TOPOLOGY_Grothendieck_Topology.md)**）。

*   **現象：** 所有經過該語義區段的觀測者，其觀測路徑都會被強制導向該黑洞。
*   **後果：** 觀測者無法看見黑洞以外的替代方案。這正是 **「語義日蝕攻擊」** 的物理本質——惡意節點透過宣告極大質量的 `#refine` 規則，囚禁了所有的觀測者。

**防禦機制：視界震盪 (Horizon Oscillation)**
觀測者必須投入額外的 $E$（能量/燃料）來執行「隨機相位擾動」，這相當於物理學中的「逃逸速度」，讓觀測者能擺脫局部重力源，重新審視更廣闊的宇宙。

## 4. 幾何引力與共識 [INTERP]

語義引力解釋了 `n/` 宇宙如何達成 **自發性共識**：
共識不是透過投票產生的，而是透過 **「引力坍縮」**。

當多個觀測者對同一個 CAID 產生觀測時，譜特徵最穩定、跡最沉重（最詳盡）的那個定義會自然而然地成為重力中心。其餘輕量級的觀測會像衛星一樣，最終被吸入重力中心，合併成唯一的、全域一致的真理。

## 5. 工程視角 (Engineering Perspective) [HEUR][ROADMAP][!!RISK!!]

語義重力是 **LADD (Lattice-Aware Distributed Discovery)** 路由算法的物理基礎：

*   **引力路由：** LADD 節點不會盲目轉發請求。它會計算查詢 Combo 與鄰居節點服務幾何之間的「語義引力」 $F_s$（基於 CAID 的 Lattice Sketch 譜摘要）。請求總是優先轉發給引力最強（格論距離 $d_L$ 最近且質量 $m$ 較重）的節點。
*   **自組織負載平衡：** 大質量的節點（專業化程度高的節點）天然吸引更多流量。然而，過大的重力會導致單點能耗上升。透過 $E=mc^2$ 的燃料定價，系統會迫使部分流量「逃逸」到次質量的節點，實現自發的負載分配。
*   **黑洞防禦：** [ROADMAP] 想像在未來的工程實作中，引擎可能提供類似 **「假想原語：`oo horizon-oscillate`」**（視界震盪）功能，確保觀測者不會被單一語義黑洞遮蔽了全域格論的其他路徑。
