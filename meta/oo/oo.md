# OO

* oo 是取自 Ouroboros (裡面很多o)； oo 又像是一個「無限」的符號，跟 Ouroboros 咬自己尾巴的形象相符。
* OODP 是 Ouroboros Discovery Protocol (發現協議)
  * 最初是為了解決套件供應鏈攻擊問題，先發想了 CAID。發現 CAID 的套件發佈方式帶有「去中心化」屬性 => 這關聯到後來的權威與信任。
  * 接著問到「發佈套件的網路層(協議)」能不能也格論化，於是把 DHT XOR 換成集合交集。我們稱這個新的構想為 LADD (Lattice-Aware Distributed Discovery)。
  * 有時會用 LADD 代稱整個由 LADD 形成的「全球語義網路」(或全球邏輯格)。
  * OODP 說明白就是 CAID + LADD。
