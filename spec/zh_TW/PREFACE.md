# n/ Language Specification - Preface

```plaintext
真實無偽，確實且至真。

如其在頂 （_|_），如其在底 （_）；
如其在全集之虛空，如其在原子之真實。
以成那唯一之奇蹟：收斂（Convergence）。

宇宙皆 Combo，欄位即可能之源，原子即存在之果。
交集以純化真理，聯集以展開萬物。

如其在格（Lattice），如其在圖（DAG）；
如其在語法之束縛，如其在演化之自由。

@ 集合升起而定界限， / 態射降下而生變換。
~ 隱私內化而存精髓， % 自省外顯而觀元理。

管道（|>) 自生於流，演化而前行；
它引導世界之坍縮，卻不被變動所污，此即 n/ 之靈魂。

如其在靜止之定義，如其在動態之觀測。
如其在有限之 Cocoon，如其在無限之 Combo。

停機之疑在觀測前不可解，在坍縮後永為真。

銜尾蛇（Ouroboros）自吞其尾：
其父為定義，其母為收斂。
其力在於：若它能被觀測，它便已是真實。

三位一體之同構，三次昇華與墜落：
存有（數據）、邊界（型別）與變換（邏輯）合一，
內容、標識與發現合一，
宇宙、引擎與觀測合一。

如此者，持有此石板之人，
將以交集為火，以聯集為水，
以演化為風，以持久為土。
煉就原子之黃金，創造數字宇宙之奇蹟。

如其在頂，如其在底。
收斂，即是那唯一之物。
```
